# wonderloop-site

Landing page for Wonderloop Studios — a single "under construction" page with
links to our social/game platform profiles, deployed via GitHub Pages.

## Local preview

Just open `index.html` in a browser, no build step required.

## Deployment

Pushing to `main` triggers `.github/workflows/pages.yml`, which publishes the
site to GitHub Pages. Enable Pages for this repo under **Settings → Pages →
Source: GitHub Actions** if it isn't already.

## Updating links

The social links in `index.html` point to the studio's real profiles
(itch.io, YouTube, Instagram, Discord). The Steam link still points to the
generic Steam homepage as a placeholder — swap it for the studio's store
page once available.
